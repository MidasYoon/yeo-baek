# 여행 기록 앱

여행 기록 하나에 여행지 정보(지도, 리스트)와 여행 다이어리를 함께 모아 두는 웹앱입니다.

## 현재 상태

아직 만들기 전입니다. 코드와 기능은 없습니다.

## 프로젝트 문서

- `README_1.md`: 이 문서입니다. 프로젝트 소개와 현재 상태를 적습니다.
- `AGENTS_1.md`: AI 에이전트가 작업할 때 지킬 규칙(목적, 환경, 작업 전, 변경 범위, 완료 확인, 안전)을 적습니다.

## 시작 방법

1. 이 README를 먼저 읽습니다.
2. 개발 환경과 사용할 기술은 아직 정하지 않았습니다. 정해지면 여기에 적습니다.

아직 미정입니다.

- 아직 없는 파일이나 기능은 적지 않습니다.
