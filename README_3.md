# 여백 (yeo-back)

여행을 기록하고, 방문한 여행지를 지도와 목록으로 보고, 날짜별로 일기를 쓰는 웹앱입니다.

## 현재 상태

- 아직 만들기 전입니다.
- 앱 안에는 AI 기능을 넣지 않습니다.

## 주요 기능

- **여행기록**: 여행명, 여행지, 기간, 여행 정보를 기록합니다.
- **여행지 정보**: 여행지를 지도와 목록으로 보여 줍니다.
- **여행 다이어리**: 여행 중 날짜별로 일기를 씁니다.

## 팀

| 이름 | 담당 |
| --- | --- |
| 서준 | 여행기록 |
| 은희 | 여행지 정보 |
| 건용 | 여행 다이어리 |

- 공통 파일(라우터 등록, 화면 레이아웃, DB 설정) 관리자: 미정
- 첫 화면(Home) 담당: 미정

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| 프론트엔드 | React |
| 백엔드 | FastAPI |
| DB | SQLite |

## 폴더 구조

```
yeo-back/
├── frontend/   # React 프론트엔드
├── backend/    # FastAPI 백엔드
├── docs/       # 프로젝트 문서
├── README.md   # 프로젝트 소개 (지금 보고 있는 문서)
├── AGENTS.md   # AI가 일할 때 지킬 규칙
└── CLAUDE.md   # Claude Code가 AGENTS.md를 자동으로 읽게 하는 파일
```

## 프로젝트 문서

| 문서 | 내용 |
| --- | --- |
| `README.md` | 프로젝트 소개와 시작 안내 (지금 보고 있는 문서) |
| `AGENTS.md` | AI가 일할 때 지킬 규칙 |
| `CLAUDE.md` | `AGENTS.md`를 불러오는 한 줄 파일 |
| `docs/DECISIONS.md` | 팀이 확정한 결정과 그 이유 |

기획서와 디자인 가이드 같은 다른 문서는 `docs/` 폴더에 만들 예정입니다.

## 시작 방법

1. 저장소를 내 컴퓨터로 받습니다.

   ```bash
   git clone <저장소 주소>
   ```

2. 프로젝트 폴더로 이동합니다.

   ```bash
   cd yeo-back
   ```

3. README.md와 AGENTS.md부터 읽습니다.

## 실행 방법

설치 명령과 실행 명령은 아직 정하지 않았습니다. 정해지면 여기에 적습니다.

| 구분 | 포트 |
| --- | --- |
| 백엔드 | 8000 (FastAPI 기본값) |
| 프론트엔드 | 5173 (Vite 기본값, 빌드 도구는 미정) |

## 확인과 기록

- 작업을 마치면 바뀐 내용을 직접 확인한 다음 커밋합니다.
- 커밋 메시지에는 무엇을 왜 바꿨는지 짧게 적습니다.
- 정해진 내용이나 바뀐 내용이 생기면 이 README에도 반영합니다.

## 참여 방법

- 기본 브랜치: `master`
- 브랜치 규칙: 미정
- 커밋 규칙: `종류(기능): 내용` 형식으로 적습니다.
  - 예: `feat(place): 방문 순서 번호 표시`, `fix(diary): 날짜 정렬 오류 수정`
- PR 절차: PR을 올리고 다른 팀원 1명이 확인한 뒤 `master`에 합칩니다.
- 공통 문서(README, AGENTS, DECISIONS 등): 팀이 합의한 뒤에는 누구나 고칠 수 있습니다.
