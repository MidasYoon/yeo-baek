## 2. 여행기록 (담당: 서준)

### 목적

어떤 여행을 했는지 한 건씩 기록한다. 그 여행의 장소와 일기를 모아 보는 기준이 된다.

### 사용자가 할 수 있는 일

- 여행을 등록한다. (R-001)
- 여행 목록을 본다. 시작일이 늦은 여행이 위에 보인다. (R-006, R-007)
- 여행 하나를 열어 본다. 여행 내용과 함께 그 여행의 장소 목록과 일기 목록이 보인다. (R-008, R-009)
- 여행을 고친다. (R-010)
- 여행을 지운다. 지우기 전에 한 번 더 확인한다. (R-011)

### 입력하는 정보

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| 여행명 | 필수 | |
| 여행지 | 필수 | |
| 시작일 | 필수 | `YYYY-MM-DD` |
| 종료일 | 필수 | `YYYY-MM-DD`. 시작일보다 빠르면 저장되지 않는다. 시작일과 같은 날은 된다. |
| 여행 정보 | 선택 | 자유 메모 한 칸 |

- 필수 항목을 비우면 저장되지 않는다. (R-002 ~ R-005)

### 다른 기능과의 연결

- 장소(여행지 정보)와 일기(여행 다이어리)는 여행 한 건에 속한다.
- 여행을 열면 그 여행의 장소와 일기만 보인다. (R-009)

### 열린 질문

- 장소·일기가 붙은 여행은 지우지 못하게 막고 먼저 지우라고 안내할지. 서준 안이며 팀 확인이 필요하다. PLAN.md에서는 P-07에서 정하기로 되어 있다. (R-012)
- 여행을 열었을 때 보이는 장소·일기 목록이 은희·건용 절의 목록과 같은 내용인지 (R-009)
- 시작일이 같은 여행이 여러 개일 때 목록 순서 (R-016)
- 여행 기간을 고쳤을 때, 이미 적은 장소·일기 날짜가 새 기간을 벗어나면 어떻게 할지 (R-017)

| R-015 | 사용자가 목록 **정렬 순서를 바꾼다**(정렬 버튼). 지운 여행을 **되살린다**(휴지통). | **AI 제안** (질문하면서 선택지에서 뺀다고 언급한 것) | 제외. 정렬 선택은 README "만들지 않는 것"(검색·필터)과 맞닿고, 되살리기는 README "주요 기능"에 없음 | — |
