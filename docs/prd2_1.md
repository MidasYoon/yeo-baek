# PRD 2-1 — 여행지 정보 (은희)

> 은희 담당 초안이다. 나중에 `docs/PRD.md`의 "여행지 정보" 절로 합친다. (D-005)
> 근거 결정: D-002 "방문한 여행지를 지도와 목록으로 보여 준다."
> "팀 논의 필요" 표시가 붙은 내용은 확정이 아니다. 맨 아래 [팀 논의 필요](#팀-논의-필요)를 본다.

## 1. 한 줄 요약

여행 하나를 고르면 **한국 지도와 핀**이 보이고, 핀을 누르면 그 지역에서 다녀온 **장소 카드**가, 카드를 누르면 **상세 다이얼로그**가 뜬다.

## 2. 장소 하나에 남기는 정보

| 항목 | 필수 | 규칙 | 예 |
| --- | --- | --- | --- |
| 지역 | 필수 | 시·도 17개 중 select로 고른다 | 서울 |
| 장소 이름 | 필수 | 20자 이하 | 경복궁 |
| 방문 날짜 | 필수 | `YYYY-MM-DD`, 그 여행의 기간 안의 날짜만 허용 | 2026-05-01 |
| 메모 | 선택 | 20자 이하, 한 줄 메모 | 줄이 길었지만 좋았음 |

- 시·도 17개: 서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주
- 긴 이야기는 여행 다이어리(건용)에 쓴다. 장소 메모는 짧게 둔다.
- 장소는 반드시 여행 하나에 속한다 (`trip_id`).

## 3. 사용자가 할 수 있는 일

| 행동 | 사용자가 겪는 일 |
| --- | --- |
| 여행 고르기 | 화면 위쪽 여행 select에서 여행 하나를 고르면, 그 여행의 지도와 핀이 보인다 |
| 장소 추가 | 고른 여행에 장소를 넣는다. 필수 항목을 비우거나 규칙을 어기면 저장되지 않는다 |
| 장소 보기 | 핀을 누르면 그 지역의 장소 카드가 뜨고, 카드를 누르면 상세 다이얼로그가 뜬다 |
| 장소 수정 | 상세 다이얼로그의 수정 버튼을 누르면, 다이얼로그 안에서 추가와 같은 폼으로 지역·이름·날짜·메모를 고친다. 규칙은 추가와 같다 |
| 장소 삭제 | 상세 다이얼로그의 삭제 버튼을 누르면 "'경복궁'을 삭제할까요?" 같은 확인 창이 한 번 더 뜨고, 확인해야 지워진다. 되돌릴 수 없다 |

## 4. 장소 화면에 들어오는 길

| 들어오는 길 | 처음 모습 |
| --- | --- |
| 여행 상세 화면의 "장소 보기" 버튼 | 그 여행이 이미 골라진 상태 |
| 네비 메뉴의 place | 여행 select가 비어 있고 "여행을 골라 주세요" 안내가 보임 |
| Home의 "최근 장소" 카드 | 그 장소가 속한 여행이 골라지고, 그 장소의 지역 핀이 눌린 상태 (카드는 보이고 다이얼로그는 열지 않는다, `prd2_2.md` 참고) |

- 네비에 trip · place · diary 3개 메뉴가 있는 반응형 구조를 전제로 한다. — **팀 논의 필요 (L-07)**
- 여행 상세의 "장소 보기" 버튼은 여행기록 화면에 놓인다. — **팀 논의 필요 (L-08)**

## 5. 지도, 카드, 상세 다이얼로그

**처음 모습**

- 여행을 고르면 지도와 핀만 보인다. 장소 카드는 핀을 눌러야 보인다.
- 핀이 하나뿐인 여행도 같다. 눌러야 카드가 보인다.

**지도**

- 한국 지도 그림(SVG) 1장 위에 핀을 찍는다. 지도 API는 쓰지 않는다.
- 핀 위치는 고른 지역(시·도)의 구역 가운데다. 사용자가 지도를 직접 클릭해 찍지 않는다.
- 같은 시·도의 장소는 핀 하나로 겹치고, 핀 위에 장소 개수(예: 3)를 표시한다.
- 지도 방식은 아직 `docs/DECISIONS.md`에 기록되지 않았다. — **팀 논의 필요 (L-02)**

**핀과 카드 연결**

- 핀을 누르면 지도 아래에 **그 지역의 장소 카드만** 뜬다. 다른 지역 장소는 보이지 않는다. — **팀 논의 필요 (L-12, L-13)**
- 다른 핀을 누르면 카드가 그 지역 것으로 바뀐다.
- 같은 핀을 다시 누르면 카드가 닫히고, 처음 모습(지도와 핀만)으로 돌아간다.
- 여행 select를 바꾸면 처음 모습으로 돌아간다.

**카드**

- 카드에는 장소 이름과 방문 날짜만 보인다.
- 순서: 방문 날짜 **오래된 순**, 날짜가 같으면 **먼저 추가한 장소**가 앞.
- 사용자가 순서를 바꾸는 기능은 없다.

**상세 다이얼로그**

- 카드를 누르면 다이얼로그가 뜬다.
- 보이는 것: 지역, 장소 이름, 방문 날짜, 메모, 수정 버튼, 삭제 버튼, 닫기 버튼.
- 수정은 다이얼로그 안에서 추가와 같은 폼으로 한다.
- 삭제는 확인 창을 한 번 더 거친다. (3절)

**시간이 모자랄 때의 대안**

- 다이얼로그 대신, 카드를 누르면 그 자리에서 카드가 펼쳐져 메모와 수정·삭제 버튼이 보이게 한다.
- 이 대안을 쓸지는 개발 중에 담당자가 정하고 팀에 알린다.

## 6. 만들지 않는 것

README의 "만들지 않는 것"(로그인, 실시간 위치 추적, 지도 API·길찾기, 날씨 API, 외부 장소 검색, 여행지 추천, 통계·차트, 검색·필터·별점, 사진 업로드)을 그대로 따른다. 여행지 정보에서 따로 정한 것은 아래와 같다.

| 넣지 않는 것 | 이유 |
| --- | --- |
| 방문 순서 번호 | 담당자가 필요 없다고 판단함. README와 다름 — **팀 논의 필요 (L-01)** |
| 필터 | README 범위 밖. 지도로 한눈에 보이므로 필요 없음 |
| 주소 입력 | 검색·지도 연동이 없어 쓰이는 곳이 없음 |
| 지도 직접 클릭으로 핀 찍기 | 시·도 select로 대신함 |
| 시·군·구 단위 지역 | 3일 일정 안에 위치를 정확히 맞출 수 없음 (SVG에 시·도 경계만 있음) |
| 장소 → 다이어리 이동 버튼 | 보류 — **팀 논의 필요 (L-06)** |

## 7. 알고 있는 한계

- 한국 지도 1장이라 **해외 여행 장소는 기록할 수 없다.**
- 같은 시·도의 장소는 핀이 겹쳐서 지도만으로는 구분되지 않는다. (핀 개수 표시와 카드로 보완)
- 핀 위치는 시·도 가운데라 실제 위치와 다르다.
- 핀을 누르기 전에는 장소 목록이 보이지 않는다. 여행 전체 장소를 한 번에 보는 화면은 없다. (L-13)
