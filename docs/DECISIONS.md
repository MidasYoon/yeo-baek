## D-004 공통 뼈대·첫 화면 담당

- **결정:** 공통 파일(라우터 등록, 화면 레이아웃, DB 설정)은 건용이, 첫 화면(Home)은 은희가 맡는다.
- **배경:** 두 역할의 담당이 "미정"이라 공통 뼈대 작업을 시작할 사람이 없었다.
- **이유:** 한 명씩 추첨으로 정했다. (AI가 임의로 고른 결과이며, 추첨 프로그램은 쓰지 않았다.)
- **다른 선택지:** 여행기록 담당(서준)이 공통 뼈대와 Home을 함께 맡는 안
- **누가·근거:** 사람이 추첨 결과를 승인함
- **영향:** 건용은 여행 다이어리와 공통 뼈대를, 은희는 여행지 정보와 Home을 함께 맡는다.
- **다시 볼 조건:** 한 사람에게 작업이 몰려 일정이 밀릴 때
- **상태:** 유효
- **날짜:** 2026-10-19
