# PRD — 무엇을 만들지

## 여행 다이어리 (건용)

여행 중 날짜별로 일기를 쓴다. (D-003)

### 일기 한 편

- 일기는 한 여행에 속한다.
- 같은 날짜에 일기를 여러 편 쓸 수 있다.
- 일기 한 편에는 날짜, 시각, 제목, 본문, 기분을 적는다.

### 쓰기

- 날짜는 그 여행의 기간 안에서만 고를 수 있다. (여행 기간은 여행기록 절과 맞춰 봐야 함)
- 기분은 아래 목록에서 하나를 고른다. 화면에는 이모지만 보인다.

  | 기분 | 이모지 |
  | --- | --- |
  | 설렘 | 🤩 |
  | 행복 | 😊 |
  | 평온 | 😌 |
  | 피곤 | 😩 |
  | 아쉬움 | 🥲 |

- 날짜, 시각, 제목, 기분을 모두 채워야 저장된다. 하나라도 비어 있으면 저장되지 않고 사용자에게 알려 준다.
- 본문은 비워도 저장된다. 비어 있어도 자동으로 채우지 않는다.
- 제목은 최대 50자다. 넘으면 저장되지 않고 사용자에게 알려 준다. 본문은 글자 수 제한이 없다.

### 보기

- 한 여행의 일기를 날짜·시각이 오래된 것부터 보여 준다.

### 고치기·지우기

- 저장한 일기는 고칠 수 있다. 고칠 때도 "쓰기"의 규칙을 따른다.
- 저장한 일기는 지울 수 있다. 지우기 전에 "정말 지울까요?"처럼 한 번 더 확인한다.
