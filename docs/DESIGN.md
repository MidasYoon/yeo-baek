# 디자인 (DESIGN)

> 화면이 어떻게 보이는지 적는다: 색, 글자, 여백, 모양 규칙. 화면에 무엇이 보이고 무엇을 할 수 있는지는 `docs/SCREEN-SPEC.md`를 따른다.
> 기준 시안은 "한지 노을"이다 (D-023). 공통 문서이므로 팀이 합의한 뒤에만 고친다 (D-007).
> "제안"이 붙은 내용은 확정이 아니다. 시안에 없어서 AI가 시안에 맞춰 제안한 것이다.

## 1. 디자인 방향

- 이름: **한지 노을**
- 한지 바탕에 단청·오방색을 포인트로 쓰고, 한옥 처마·색동·조각보·문살 같은 한국 전통 무늬를 장식으로 쓴다.
- 차분하고 단정하게 보인다. 모서리는 거의 각지게(4px), 그림자는 옅게 쓴다.
- **빨간 원 모양은 쓰지 않는다.** 일본 국기처럼 보이기 때문이다. 동그란 표시가 필요하면 마름모를 쓴다 (7절).

## 2. 색

토큰 이름과 값은 확정이다 (D-025). 글꼴·간격·모양 토큰 이름은 D-025에 적었다.

| 토큰 (제안) | 값 | 이름 | 쓰는 곳 |
| --- | --- | --- | --- |
| `--color-bg` | `#FAF5EC` | 한지 | 페이지 바탕 |
| `--color-surface` | `#FFFDF8` | 미색 | 카드, 목록, select, 확인 창 바탕 |
| `--color-surface-sunken` | `#F3EADB` | 짙은 한지 | 그림 바탕, 날짜 묶음 머리 (`#F6EEE1`도 같은 쓰임) |
| `--color-line` | `#E8DCCB` | 선 | 카드 테두리, 헤더 아래 선, 구분선 |
| `--color-line-strong` | `#DCCBB5` | 진한 선 | select·보조 버튼 테두리 |
| `--color-text` | `#2B211B` | 먹 | 본문, 제목 |
| `--color-text-muted` | `#6E5D50` | 흐린 먹 | 지역·날짜 같은 보조 글자, 네비의 지금이 아닌 메뉴 |
| `--color-accent` | `#B23A2B` | 주홍 (단청) | 주요 버튼, 지금 메뉴의 밑줄, 고른 핀, 강조 카드 왼쪽 띠 |
| `--color-accent-deep` | `#862C20` | 짙은 주홍 | 옅은 주홍 바탕 위 글자, 입력 오류 문구 |
| `--color-accent-soft` | `#F6E7E6` | 옅은 주홍 | 강조 카드·펼친 일기 바탕 |
| `--color-indigo` | `#2C4A6B` | 쪽빛 | 지도 솟대 핀의 새(2026-10-23. 전에는 깃발 → 노리개), 장소 강조 줄, 지역 도장, 처마 아래 보, 포커스 테두리 |
| `--color-gold` | `#C99A2E` | 송화 | 장식에만 쓴다 (색동·조각보) |
| `--color-green` | `#3E7A6A` | 청록 | 장식에만 쓴다 (색동·조각보) |

- 옅은 주홍과 짙은 주홍은 주홍에 흰색 88%, 검정 25%를 섞은 값이다. 포인트 색을 바꾸면 함께 다시 계산한다.
- 송화·청록은 흰 글자를 올리면 잘 읽히지 않으므로 글자 바탕으로 쓰지 않는다.
- 명암 대비 (8절 기준을 넘는지 확인한 값, 어림값)

  | 글자 / 바탕 | 대비 |
  | --- | --- |
  | 먹 / 한지 | 약 14:1 |
  | 흐린 먹 / 한지 | 약 5.7:1 |
  | 흰색 / 주홍 | 약 6:1 |
  | 주홍 / 한지 | 약 5.5:1 |
  | 짙은 주홍 / 옅은 주홍 | 약 7:1 |
  | 흰색 / 쪽빛 | 약 9:1 |

## 3. 글자

글꼴은 Google Fonts에서 불러온다 (D-023). 설치할 패키지는 없다.

```text
https://fonts.googleapis.com/css2?family=Hahmlet:wght@500;700;800&family=IBM+Plex+Sans+KR:wght@400;500;700&display=swap
```

| 쓰임 | 글꼴 | 대체 글꼴 |
| --- | --- | --- |
| 제목, 로고, 카드 이름, 날짜 묶음 제목, 펼친 일기 본문 | Hahmlet | `serif` |
| 본문, 버튼, 입력 칸, 보조 글자 | IBM Plex Sans KR | `sans-serif` |
| Home 큰 문구의 한자 旅·白 (900) | Noto Serif KR. 이 두 글자만 받는다 (D-031) | Hahmlet → `serif` |

| 단계 | 크기 / 굵기 | 글꼴 | 쓰는 곳 |
| --- | --- | --- | --- |
| 화면 제목 | 44px / 800 | Hahmlet | "여행 기록", "여행 장소", "여행 일기" (메뉴 이름에 맞춤, D-035) |
| Home 큰 문구 | 52px / 800, 줄 간격 1.3 (2026-10-23 팀 합의. 전에는 54px, 1.25) | Hahmlet | Home 첫 화면 (11절 닫은 질문) |
| 블록 제목 | 28px / 800 (2026-10-23. 전에는 30px) | Hahmlet | Home "최근 기록" |
| 카드 제목 | 26px / 700 (Home 카드는 24px, 두 줄까지 넘치면 "…", 2026-10-23) | Hahmlet | 여행 카드, Home 카드 |
| 작은 카드 제목 | 21~22px / 700 | Hahmlet | 장소 카드, 날짜 묶음 제목 |
| 로고 | 24px / 800 | Hahmlet | 네비 "여백" |
| 본문 | 15~16px / 400·500 | IBM Plex Sans KR | 일기 접힌 줄 제목, 메모, 여행 정보 |

- 모바일(768px 미만)에서는 화면 제목을 32px, Home 큰 문구를 38px로 줄인다 (제안).
- 제목(h1~h3)은 자간 -0.02em (시안). 한국어는 낱말 단위로 줄을 바꾸고(`keep-all`), 띄어쓰기 없이 긴 글은 칸 끝에서 끊는다 (제안, 2026-10-22)
- 움직임 줄이기를 켠 사용자에게는 전환·움직임을 모두 끈다 (제안, 2026-10-22)

## 5. 반응형

화면 폭 기준은 768px 하나다 (SCREEN-SPEC 2절).

| 화면 | 768px 이상 | 768px 미만 |
| --- | --- | --- |
| 네비 | 가로 한 줄 | 가로 한 줄 그대로 |
| Home 카드 | 가로 3칸 | 1칸씩 쌓기 |
| 여행기록 카드 | 한 줄에 하나 (조각보 96px) | 한 줄에 하나 (조각보 64px), 오른쪽 화살표 숨김 |
| 여행지 정보 | 왼쪽 지도(폭 40%), 오른쪽 장소 목록(60%, 판 하나에 줄로 쌓기). 지도는 스크롤해도 위쪽에 붙어 있다 (2026-10-22, 폭은 2026-10-23. 전에는 187~267px) | 지도 → 목록 순서로 쌓기. 지도는 화면 폭에 꽉 차게 (2026-10-23) |
| 여행 다이어리 | 위에서 아래로 쌓기 | 같음. 접힌 줄의 좌우 여백 16px |
| AI 추천 대화창 (D-037) | 오른쪽 아래에 뜨는 380px 창 | 화면 전체 |

## 6. 공통 부품 모양

### 네비
- 왼쪽에 처마 로고 + "여백"(Hahmlet 24px 800), 로고 옆 80px 띄워 `여행 · 장소 · 일기` (17px 500, 흐린 먹, D-032). 메뉴는 로고와 세로 가운데를 맞춘다. 헤더 폭은 본문과 같은 1080px라 로고와 화면 제목의 왼쪽 끝이 맞는다 (2026-10-23 팀 합의. 전에는 로고 옆 32px, 15px)
- 메뉴 사이 64px, 768px 미만에서는 로고와 메뉴 사이·메뉴 사이 모두 32px (2026-10-23 팀 합의. 전에는 48px, 그 전에는 24px)
- 지금 메뉴: 먹색, 굵게(700), 주홍 밑줄 3px. 밑줄은 헤더 아래 선 위에 겹쳐 붙인다 (2026-10-23 팀 합의. 전에는 글자 아래 10px). 메뉴마다 굵은 글자 폭만큼 자리를 미리 잡아, 지금 메뉴가 바뀌어도 글자가 좌우로 움직이지 않는다 (2026-10-22 사람이 요청함)
- 스크롤바가 있는 화면과 없는 화면을 오가도 헤더가 움직이지 않게 `html`에 `scrollbar-gutter: stable`을 둔다 (`global.css`)
- 헤더 아래 1px 선 (`--color-line`)

### 버튼
- 크기는 세 종류가 모두 같다: 높이 48px, 글자 15px, 좌우 20px, 최소 폭 96px. 종류는 색과 굵기로만 나눈다 (2026-10-23 팀 합의. 전에는 주요 52px·16px, 보조·글자 44px·14px)

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| 주요 | 주홍 바탕, 흰 글자 700, 앞이나 뒤에 선 아이콘 | "여행 추가", "장소 추가", "일기 추가", 저장 (제안), 확인 창의 "지우기" (제안) |
| 보조 | 미색 바탕, 진한 선 테두리, 먹 글자 500 | 수정·삭제(여행 상세·장소·일기), 취소 (제안), "사진 추가", "다시 시도" (제안) |
| 글자 | 바탕 없음, 밑줄, 흐린 먹 500 | 지금 쓰는 곳 없음 (2026-10-23 장소 수정·삭제는 보조로, 사진 빼기는 × 버튼으로 바꿈). 부품에는 남겨 둔다 |

- 추가 버튼 글자는 "○○ 추가"로 맞춘다: "여행 추가", "장소 추가", "일기 추가". 추가 화면의 제목도 같다 (2026-10-23 사람이 정함. 전에는 "새 여행 만들기", "새 일기 쓰기"). 예외: Home 첫 화면의 바로가기는 앞에 + 선 아이콘(18px)을 두고 "+ 새 여행 추가"로 쓴다 (2026-10-23 사람이 정함)
- 수정 화면 제목은 "○○ 수정"으로 맞춘다: "여행 수정", "장소 수정", "일기 수정" (2026-10-23 사람이 정함. 전에는 "일기 고치기")
- 사진 칸 버튼 글자는 "사진 추가"이고, 사진 1장 칸(여행·일기)에 사진이 있으면 "사진 변경"이다 (2026-10-23 사람이 정함. 전에는 "사진 고르기", "다른 사진 고르기")
- 목록 화면의 추가 버튼은 화면 제목 오른쪽에 둔다 (2026-10-23)
- 폼의 취소·저장은 폼 아래 오른쪽에 "취소"(보조) · "저장"(주요) 순서로 둔다

- 누를 수 없을 때 (저장·지우기를 기다리는 중): 불투명도 50%, 커서 `not-allowed` (제안)
- 키보드 포커스: 쪽빛 2px 테두리, 2px 띄움 (제안)
- 마우스를 올림 (제안, 2026-10-22): 주요는 짙은 주홍 바탕, 보조는 짙은 한지 바탕 + 흐린 먹 테두리, 글자는 짙은 한지 바탕 + 먹 글자(밑줄 4px 띄움). 누르는 순간 아래로 1px. 바뀌는 데 0.15초
- 네비의 지금이 아닌 메뉴에 마우스를 올리면 먹색이 된다 (제안, 2026-10-22)

### Home (시안대로 맞춤, 2026-10-22)
- 큰 문구는 "여백" 이행시 두 줄이고, 두 줄의 첫 글자를 한자 旅·白로 써서 주홍으로 보인다 (2026-10-22 사람이 정함)
- "최근 기록" 제목 → 오른쪽 끝까지 가는 1px 선 (처마 장식은 2026-10-22 사람의 요청으로 뺌)
- 한옥 매거진 모양 (2026-10-23 팀 합의)
  - 머리글(13px 700 주홍, 자간 0.1em)은 큰 문구 바로 위 12px에 붙인다 (2026-10-23 사람이 요청. 잠깐 두었던 위아래 선과 오늘 날짜의 "표지 줄"은 뺌)
  - 글과 그림을 1 : 1로 둔다 (2026-10-23. 잠깐 6 : 5). 소개 문장은 17px, 한 줄 최대 30em, 마지막 줄에 낱말 하나만 남지 않게. "+ 새 여행 추가" 버튼은 소개 문장 아래 36px
  - 한옥 그림 (2026-10-23 팀 합의로 다시 그림): 처마 끝이 올라간 곡선에 수막새, 기와골, 서까래 끝, 공포, 단청 띠, 띠살문과 열린 대청, 먹 번짐 세 겹 산, 소나무 솔잎, 왼쪽 위 매화 가지(미색·옅은 분홍 꽃)
  - 한옥 그림은 창호 액자: 미색 8px 여백 + 1px 선 + 카드 그림자, 그림 자체도 1px 선. 오른쪽 아래 모서리에 인장, 액자 왼쪽 바깥에 세로쓰기 旅白, 아래 12px에 캡션 "처마 끝에 걸린 오늘"(13px 흐린 먹) (7절)
  - 첫 화면과 "최근 기록" 사이 80px (768px 미만 48px)
- 카드: 안쪽 여백 위 32px·좌우 28px·아래 24px, 카드 사이 24px (2026-10-23. 전에는 아래 28px, 사이 28px). 날짜 위에 1px `#ccc` 구분선(위 12px 띄움) (2026-10-23 팀 합의. 색동 띠 아래 2px 선은 더했다가 사람의 요청으로 뺌). 이름표 13px 700 자간 0.1em, 색은 여행 짙은 주홍·장소 쪽빛·일기 짙은 청록 `#2F6253`(장식 색 청록에 검정을 섞어 글자 대비를 맞춘 값)
- 카드 안: 이름표 → 제목 → 보조(여행지·지역, 15px 흐린 먹) → 날짜(14px 500 먹). 날짜는 카드 아래쪽에 붙여 세 카드가 같은 높이에 보인다
- 카드 제목은 세 카드 모두 두 줄까지 보이고 넘치면 끝에 "…" (2026-10-23 사람이 정함. 전에는 일기만 한 줄). 한 줄 제목도 두 줄 높이를 차지해 세 카드의 보조 줄과 날짜가 같은 높이에 온다
- 최근 일기 카드: 제목 아래에 본문 첫머리 두 줄(Hahmlet 15px 흐린 먹, 줄 간격 1.7, 넘치면 "…") (2026-10-23 사람이 요청)

## 8. 접근성

- 글자와 바탕의 명암 대비는 4.5:1 이상 (24px 이상 큰 글자는 3:1 이상). 2절 표를 따른다.
- 누르는 곳은 높이 44px 이상.
- 버튼은 `<button>`, 화면 이동은 `<a>`로 만든다. 아이콘만 있는 버튼에는 `aria-label`을 넣는다.
- 색만으로 구분하지 않는다. 고른 핀은 색과 함께 크기와 테두리도 다르다.
- 별점 청사초롱은 색만으로 구분하지 않는다. 켜진 초롱은 채워지고 꺼진 초롱은 테만 있다. 초롱 줄 전체에 "별점 5점 중 4점" 이름을 두고, 폼은 라디오 버튼 5개("1점"~"5점")로 만든다 (D-043, 제안).
- 사진에는 대체 글자(`alt`)를 넣는다: "여행 대표사진", "장소 사진", "일기 사진" (SCREEN-SPEC 1절, 제안). 프로필사진은 옆에 닉네임 글자가 있으므로 빈 `alt`("")로 둔다 (D-042, 제안).
