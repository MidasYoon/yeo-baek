# 작업 계획

## 이번 목표와 범위

- **목표:** PRD에서 "포함"인 요구사항을 동작하는 웹앱으로 만든다.
- **범위 안:** `frontend/`·`backend/` 코드 작성, 작업 목록 P-11~P-14, P-19~P-39. P-35~P-39(사진)는 2026-10-22 팀 합의로 더함 (D-033). P-66~P-69(AI 여행지 추천)은 2026-10-23 팀 합의로 더함 (D-037). P-70~P-75(회원·좋아요·댓글)는 2026-10-23 팀 합의로 더함 (D-042)
- **하지 않을 일:** PRD에 없는 기능, 앱 안의 AI 기능(AI 여행지 추천만 예외, D-037), 로그인 밖의 계정 기능(비밀번호 찾기·탈퇴 등, D-042), 인터넷 공개
- 패키지·도구 설치는 범위 안이지만, 설치할 때마다 사람이 승인한다 (AGENTS.md "안전").
- 설계 단계(P-01~P-10)의 목표와 범위는 "남은 문제와 다음 행동"에 기록으로 남긴다.
